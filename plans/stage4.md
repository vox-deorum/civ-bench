# Stage 4: analyses

**Goal.** Implement the pluggable analysis layer and the **core** modules. Each is a self-contained unit behind the `Analysis` interface + registry; JSON selects it by name; it returns an `AnalysisResult` (tables + figures + summary), never side effects. **Status: built & validated.**

**Layout as built.** `bench/analyses/` holds `base.py` (`Analysis` + `AnalysisResult` + `AnalysisContext`), `errors.py` (`AnalysisError`), `registry.py` (name → class; reserved/optional names resolve to a loud "registry-reserved" error), `runner.py` (`run_analysis` → builds the context, runs the module, persists tables to `<root>/analyses/<id>/*.csv` + figures to `*.png`), and `grouping.py` (the `argmax` grouping label). Modules live under `ratings/`, `prediction/`, `calibration/`, `performance/`, `exploratory/`. The CLI dispatches `node.kind == "analyses"` to `run_analysis`; per-module `params` schemas live in `bench/config/schema.py` (`ANALYSIS_PARAM_KEYS` + enum domains) and are enforced in `loader._validate_analysis_params` (import-light, so the dry-run path stays torch/matplotlib-free). Estimator-consuming analyses that should treat omitted/empty `uses.estimators` as "all enabled estimators" opt in on the individual analysis class with `default_all_estimators = True`; the config DAG reads that flag via `bench/config/analysis_metadata.py` without importing the heavy analysis registry. R-backed ratings are gated on `find_rscript`; absent R raises a clean `AnalysisError`.

## Files to create / port

- `bench/analyses/base.py`: `Analysis` interface + registry (name → class) and `AnalysisResult`.
- **ratings** (`analyses/ratings/`, consume `strength` via `uses.tables:["strength"]`): `ratings.bradley_terry`, `ratings.plackett_luce`, `ratings.matchups`. Port from `../vox-deorum-analysis/ratings/` (keep R interop; `Rscript` via `PATH`/`CIV_BENCH_RSCRIPT`). **strategy-Elo and bootstrap are params, not modules:** `group_by` (default `["player_type"]`; `["player_type","strategy"]` = per-strategy) and `bootstrap` (shared resample-and-refit). **The `bootstrap` resample re-runs the parts of the `adjust/strength` fit that are re-estimated from the resampled games** (resample games upstream of the strength fit, not a fixed panel): the uncontrolled civ OLS is refit per replicate when `civ_adjust:"ols_logit"` (and needs no refit under `"none"`). **The per-cell baseline (both implicit and explicit) is held *constant* across replicates (option C)**, read from the adjust stage's persisted `cell_baseline.csv` (computed once from the full, unfiltered panel) and keyed by `(experiment, seed, player_id)` (implicit) / `(seed, player_id)` (explicit). Recomputing the implicit baseline from each rating-filtered resample was rejected: `only_llm`/`min_games` drop the Vanilla reference rows the point estimate used, so replicates would silently lose evidence and diverge from the point estimate. The tradeoff: holding it fixed keeps every replicate scaled exactly like the point estimate but does not propagate the (often small-`n`) baseline's own noise into the CIs. A `"cell"` row whose fixed baseline is absent falls back to civ/relative; a per-replicate civ-OLS failure drops that whole replicate (it is not counted), and `post_cell_normalize:"relative_to_leader"` is re-applied inside each replicate so the scaling matches the point estimate.
- **prediction** (scoring, `analyses/prediction/`): `prediction.evaluate` (multi-metric table), `prediction.compare`. Port from `predict/` loader + comparison logic.
- **calibration** (`analyses/calibration/`): `calibration.reliability`, `calibration.loss_by_progress`, `calibration.civ_effects`, `calibration.cell_baseline`.
  - **`calibration.cell_baseline` (controlled-design only): implicit-vs-explicit cell-baseline heatmap.** Consumes the adjust stage's `cell_baseline.csv` (+ `cell_coverage.csv` for missing-cell marking); renders **per `seed`** (split so each panel stays small) a heatmap whose **rows are conditions** (`experiment`: the implicit per-experiment baselines) and whose **columns are the `(seed, player_id)` cells** of that seed, each column labeled with its seat-bound `civilization` (fixed per `(seed, player_id)`). Cell color = `cell_baseline` on the **logit scale**: a diverging map centered at 0 with **shared, robust symmetric limits** across the per-seed facets, percentile-clipped so the enforced-winner/clip sentinel `logit(1−eps) ≈ 11.51` does not saturate the scale, with sentinel/clipped cells given a distinct marker. Each cell is annotated with **`n_vanilla`**, the count of Vanilla/VPAI rows the baseline averages (the estimate's support); cells the experiment is missing (`cell_coverage.missing` / `n_vanilla == 0`) are hatched/blanked. Because the **explicit pathway is the single shared baseline** spanning the whole grid, it is pinned as a **top reference row separated by a rule**, so each implicit condition's cell can be read against the explicit baseline directly above it; both pathways are drawn together when present, and an implicit-only (`baseline_experiment:null`) run omits the explicit reference row. The explicit condition's **own implicit row is dropped**: it averages the same Vanilla cells as the explicit baseline, so it would merely duplicate the pinned reference row. Emits one figure per `seed` in `AnalysisResult.figures`; returns an empty result (no figures) when there are no controlled rows. Adds a catalog-styled `bench/plotting/heatmap.py` (ported per the stage-0 "plotting helpers per-analysis as needed" convention).
  - **`calibration.civ_effects` (civ adjustment): per-civilization adjustment effects.** Visualizes the adjust stage's `civ_effects.csv` (`civilization, civ_effect, n_rows`): a **sorted horizontal bar/lollipop** of `civ_effect` on the **logit scale**, diverging-colored by sign and centered at 0 (the Sum-coded effects sum to ~0), each bar annotated with **`n_rows`**, the panel rows backing that civ's effect. This is the per-civ counterpart to `calibration.cell_baseline`'s per-cell baseline; `civ_effects.csv` carries no CI (it is a single point OLS effect), so it is a bar/lollipop, **not** a forest plot (the existing `plot_forest_plot` needs CIs). **Note (stage3 §3): the civ OLS is fit on *all* panel rows (controlled rows are included in the fit: they just don't have the civ effect *subtracted*, taking the cell path instead), so `civ_effects.csv` is populated whenever `civ_adjust:"ols_logit"` ran, *including fully controlled runs*; `n_rows` therefore counts controlled+uncontrolled rows per civ, not uncontrolled-only.** Renders only when `civ_effects.csv` is non-empty (i.e. `civ_adjust:"ols_logit"`, not `"none"`); empty result (no figures) otherwise.
- **performance** (`analyses/performance/`): `performance.score_ratio` (uses `stats/`), `performance.strength_panel` (consumes `strength`), `performance.turn_predicted` (uses an estimator), `performance.controlled_seed_report` (games + panel + one `strength` table + one estimator; the data side of the stage-5 controlled-seed report, full design in [controlled-seed-report.md](controlled-seed-report.md) and schema in `configs/benchmark.md` §6.2). **`performance.strength_panel` always reports per-identity `n_games` + bootstrap CI *and* flags identities below `min_games_preliminary` as preliminary. When that param is omitted the threshold is *inherited* from the run's enabled `ratings.*` stages' `min_games` (the max across them, the cutoff the run actually rates against), falling back to `5` when no ratings stage supplies a positive cutoff; the adjust stage's three audit trails are surfaced in exactly one place each (no overlap): the per-civ uncontrolled effect (`civ_effects.csv`) by `calibration.civ_effects` and the per-cell controlled baseline (`cell_baseline.csv`, both pathways, stage3 §5.1) by `calibration.cell_baseline` (both calibration group above), while `strength_panel` owns the controlled-design **cell-coverage report** (`cell_coverage.csv`: which `(seed, player_id)` cells of the entirety each controlled experiment is missing), rendered once here as its preliminary-ness completeness table; `calibration.cell_baseline` only *consumes* that file to mark missing cells, it does not re-render the coverage table.**

- **exploratory** (`analyses/exploratory/`): `exploratory.model_token_costs` (tokens table + pricing).
- Optional modules (ablation_bt, vanilla_slot_effect, winner_trajectories, elo_comparison, context_slicing, permutation_importance, panel, turn, strategy_profiles) are **registry-reserved, `enabled:false`**, shipped only in `benchmark.full.template.json`. `behavior.*` is deferred (not built). **`ratings.vanilla_slot_effect` doubles as the controlled-design validation**: with stage3's start-cell adjustment on, the seat/start-position effect should be significant on the raw panel and ~null on the adjusted panel.

## Config wiring (`analyses[]`)

Common envelope: `id`, `module`, `uses.{estimators,tables}`, `filter` (narrows the global filter), `params`. `ratings.*` must reference a `strength` table; metrics live in `prediction.evaluate`, not in the estimator.

## Done

Every core analysis runs and returns a populated `AnalysisResult`; unknown `params` are validation errors; `group_by:["player_type","strategy"]` produces per-strategy ratings via the `strategy` grouping.
